# AssetVault

AssetVault is a full-stack Asset Tracking System developed using React and Spring Boot. The application helps manage asset information in an organized and efficient way.

## Features

- Add and manage asset details
- View all registered assets
- Store asset code, name, category, assigned person, and status
- RESTful API integration between frontend and backend
- Database persistence using Spring Data JPA
- React-based user interface

## Tech Stack

### Frontend
- React
- JavaScript
- HTML
- CSS

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST APIs

### Database
- MySQL

## Project Flow

React Frontend → REST API → Spring Boot → Service Layer → DAO → MySQL

## Purpose

The project was developed as a hands-on application to understand full-stack development using React and Spring Boot, including REST API development, database integration, JPA, and layered backend architecture.
